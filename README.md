# LINE 已讀雷達 v0.1

Android 本機原型。它不使用 LINE 官方 API，也不讀 LINE 私有資料庫；只在 Android 無障礙服務能取得 LINE 畫面 UI 時，偵測指定聊天室中新出現的「已讀」狀態。

## 第一版功能
- 指定 1 個 LINE 顯示名稱
- 進入指定聊天室後建立目前已讀基準
- 偵測新的「已讀」後跳通知與震動
- 紀錄首次偵測時間與監控經過時間
- 最多保留 50 筆本機紀錄
- 不需要 LINE 密碼、不 Root、不攔截封包、不上傳聊天內容

## 重要限制
- LINE 完全在背景、螢幕關閉或 UI 不可讀時，無法保證即時偵測。
- 紀錄的是「本 App 第一次看到已讀」的時間，不是 LINE 伺服器提供的真實閱讀時間。
- LINE UI 改版、聊天室捲動或畫面未停在底部，可能造成漏判或誤判。

## Build
